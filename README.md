# moldcron

Mold validation gates for cron inputs before they hit prod.

**Site:** https://theworker02.github.io/moldcron/

## Install / run

```bash
git clone https://github.com/theworker02/moldcron.git
cd moldcron
node src/cli.js
node --test
```
